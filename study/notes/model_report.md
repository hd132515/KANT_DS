# 학습 회원 이탈 예측 — 모델 개발 보고서 (1차)

작성 2026-11-11 · 근거 노트 `notes/mine/eda1` · 데이터 `data/Study.공유.csv`

## 1. 요약

- 목표: 회원의 최근 3개월 학습·시험 기록으로 이탈(survived = 0)을 예측. 평가지표 AUC-ROC.
- 데이터 30,664명, 이탈 868명 (2.83%). 극단적 불균형이라 정확도 대신 AUC 로 평가한다.
- 최종 모델: **MLP(시드 5개) + 로지스틱 회귀 + HistGradientBoosting 순위 평균 앙상블, val AUC 0.687 ± 0.004**.
- 예측력의 주 원천은 두 가지다.
  1. **직전 달 학습 지표 하락** — StudyIndex_M1 단독 AUC 0.661, StudyCnt_M1 0.648.
  2. **Exam2·Exam3 미응시** — 3개월 기록이 있는 회원에서 미응시 시 이탈률 1.6–2.3배.
- 시험 점수 자체와 그 변화량·변화율은 예측력이 거의 없다 (단일 AUC 0.50–0.54).

| 단계 | 입력 | 모델 | val AUC |
|---|---|---|---:|
| 1 | 시험 응시 여부 9개 | interaction (soft-AUC) | 0.609 |
| 2 | + Month | interaction (soft-AUC) | 0.621 |
| 3 | AGE 제외 전 피처 + 결측 지시 | MLP (soft-AUC), 단일 시드 | 0.673 |
| 4 | 〃 | MLP 시드 5개 평균 | 0.680 |
| 5 | 〃 | MLP + 로지스틱 + HGB 앙상블 | **0.687** |

## 2. 데이터와 평가 방식

- 피처: Month(잔류기간), AGE, 그리고 M1(직전월)·M2·M3 각각의 StudyCnt(학습 횟수), StudyIndex(학력 지수), Exam1–3.
- 결측: M1 → M3 로 갈수록 늘어난다 (Exam3_M3 29.4%). StudyCnt·StudyIndex 는 같은 행에서 함께 빠진다.
- 평가: StratifiedKFold(5, shuffle) 를 시드 0–4 로 5번 반복 = 25 폴드. 모든 모델이 같은 폴드를 쓰므로 폴드끼리 짝지어 비교한다.
  수치는 "반복별 5-fold 평균"의 평균 ± 반복 간 표준편차. 폴드 간 표준편차는 0.014–0.018 이다.
- 손실: 1 − soft-AUC. AUC 의 계단 함수 1[s_이탈 > s_잔류] 를 σ((s_이탈 − s_잔류)/τ) 로 바꿔 미분 가능하게 만들고,
  모든 (이탈, 잔류) 쌍의 평균을 최대화한다.

### 3.2 직관: 학습 경험이 나쁘면 이탈한다 → 시험 성적 추이로 볼 수 있다

시험 총점(Exam1+2+3, 세 시험 모두 있는 달만)과 월간 변화량·변화율을 라벨별로 비교했다
(`figures/feat_eng_trial/`, box 판은 `figures/feat_eng_trial/box/`). Mann-Whitney U 검정:

| 피처 | 이탈 중앙값 | 잔류 중앙값 | p |
|---|---:|---:|---:|
| 총점 M3 | 300.1 | 302.9 | 0.13 |
| 총점 M2 | 299.3 | 301.6 | 0.12 |
| 총점 M1 | 293.2 | 299.2 | **0.004** |
| 총점 변화량 M3→M2 / M2→M1 | −2.15 / −2.41 | −1.64 / −1.83 | 0.53 / 0.13 |
| 총점 변화율 M3→M2 / M2→M1 | −0.70% / −0.81% | −0.54% / −0.60% | 0.53 / 0.12 |
| StudyIndex 3개월 합 | 163 | 188 | 3e-32 |

- 이탈 회원의 총점은 M3 → M1 로 내려가고, M1 총점 차이(6점)는 유의하다.
- 그러나 변화량·변화율은 유의한 차이가 없다. 분포 폭(수십 점)에 비해 차이가 0.5점 수준이다.
- 결론: 시험 성적 추이 가설은 약하게만 지지된다. 성적보다 학습 지표(StudyIndex·StudyCnt)의 직전 달 하락이 훨씬 강하다.

### 3.3 새 가설: 이탈 회원은 시험을 보지 않는다

변수별 결측률을 라벨별로 비교했다 (`figures/label_cond_stat/missing_rate.png`).

- Exam2_M1 결측 22.0% vs 10.3%, Exam3_M1 35.9% vs 19.2% — 이탈 회원이 시험을 훨씬 많이 건너뛴다.
- Exam1·StudyCnt·StudyIndex 의 결측은 오히려 잔류 회원이 조금 높다.

### 3.4 미응시 패턴 검정 (`ml/no_exam/pattern_test.py`)

**교란**: 가입 1–2개월 회원은 M2·M3 기록 자체가 없어 '미응시'로 잡히고 이탈률도 낮다(1.0–1.7%).
그래서 3개월 기록이 있는 회원 26,123명만으로 Fisher exact + Benjamini–Hochberg 검정을 다시 했다
(`ml/no_exam/results/missing_by_feature.png`).

| 시험 | M1 | M2 | M3 |
|---|---|---|---|
| Exam1 | 2.89% vs 2.98% (n.s.) | 2.96% vs 2.97% (n.s.) | 2.90% vs 2.98% (n.s.) |
| Exam2 | **5.97% vs 2.61%** (×2.29) | **5.41% vs 2.69%** (×2.01) | **4.51% vs 2.81%** (×1.61) |
| Exam3 | **5.31% vs 2.41%** (×2.21) | **4.81% vs 2.56%** (×1.88) | **4.49% vs 2.65%** (×1.69) |

- **Exam2·Exam3 미응시는 모든 달에서 이탈률을 높이고, 최근 달일수록 효과가 크다. Exam1 미응시는 무관하다.**
- 패턴 단위로 가장 위험한 것: E2M1 + Exam3 전 달 미응시 10.6% (n=123), E2·E3 의 M1·M2 미응시 7.6% (n=171).
- 해석(가설): Exam2·3 이 난도가 높거나 심화 과목이라, 여기서 손을 놓는 것이 이탈의 전조일 수 있다. 데이터만으로는 과목을 알 수 없다.

## 4. 모델 개발

### 4.1 응시 여부만으로 (`ml/no_exam/`)

- 입력: 9개 시험 × 달의 응시 여부 T/F. 가능한 패턴 512개 중 195개 관측.
- 입력이 이산값이라 패턴별 이탈·잔류 수로 쌍 가중치를 만들어 soft-AUC 를 근사 없이 계산했다.
- 모델 비교 (val AUC): interaction 0.609 > table 0.606 > linear 0.602 ≈ mlp 0.601. 패턴별 이탈률을 그대로 쓰면 0.590 (과적합).
- 응시 여부만으로는 0.61 이 한계다.

### 4.2 + Month

- 3.4 의 교란(신규 회원)을 모델이 구분하도록 Month 를 [Month/39, log(Month)/log(39)] 로 추가했다.
- interaction 0.609 → **0.621** (+0.012, 19/25 폴드 개선), mlp +0.011, linear +0.007.
- Month 단독 AUC 는 0.526 이므로 이득은 응시 패턴과의 상호작용에서 나온다.

### 4.3 AGE 제외 전체 피처 MLP (`ml/mlp_all/`)

- 입력 31개 = 원 피처 16개 + 결측 지시 15개. 원 피처는 학습 폴드 기준 표준화 후 결측을 0 으로 채웠다
  (원 척도 평균 대체와 같다. 원 척도 0 으로 채우면 Exam1 의 실제 0점과 섞인다).
- MLP 31→64→64→1, soft-AUC, 학습 폴드의 10% inner 셋 AUC 로 조기 종료.
- val AUC **0.673 ± 0.008**. 같은 입력의 로지스틱 회귀 0.677 과 비슷하다.
- 조기 종료 지점이 20–110 step 으로 이르고 train 0.72 / val 0.67 — 이탈 868명 규모에서는 비선형 용량의 이득이 작다.

### 4.4 앙상블 (`ml/ensemble/`)

검증 폴드 안에서 점수를 순위로 바꿔 동일 가중 평균. 15개 조합을 모두 평가했다.

| 조합 | val AUC | MLP 대비 (우위 폴드) |
|---|---:|---:|
| **mlp + logreg + hgb** | **0.687 ± 0.004** | +0.007 (22/25) |
| mlp + hgb | 0.686 | +0.007 (22/25) |
| 4개 전부 (+ no_exam) | 0.684 | +0.005 (18/25) |
| mlp (시드 5개) | 0.680 | – |
| hgb | 0.678 | −0.002 |
| logreg | 0.677 | −0.003 |

- 시드 평균만으로 MLP 0.673 → 0.680.
- 이득은 트리 모델(HGB)을 섞을 때 나온다. MLP 와 로지스틱은 같은 정보라 둘만 섞으면 +0.002.
- no_exam 은 결측 지시로 이미 들어간 정보라 섞으면 오히려 떨어진다.
